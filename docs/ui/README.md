# Voice Buddy 首版 UI 设计

打开 [交互原型](index.html) 查看四个场景。此文件是无需服务器的静态设计原型；权限、模型与录音均为模拟，不代表功能已经实现。

## 设计方向

以安静的绿色和温暖的中性色表达本地、可靠；主要操作使用高对比绿色。主界面是菜单栏应用的设置和首次引导，日常听写只出现紧凑浮窗。原型中的快捷键、文本和模型准备状态均为示意，最终需按设备检测与用户设置展示。

## 首版流程

1. 首次使用：解释处理边界；分别申请麦克风和辅助功能权限，展示拒绝后的系统设置入口；下载并准备首期千问 ASR 模型；整理可选无模型规则或本地 Qwen，显示各自大小、进度、失败重试及磁盘空间。原型以模拟按钮概括此流程。
2. 就绪：菜单栏显示就绪、缺少权限或模型未安装；提供开始听写、设置和退出入口。默认快捷键暂定为 ⌥ Space，采用按一次开始、再按一次结束；可重新设置并提示冲突。不同键盘及系统快捷键冲突需实测，无法使用或发生冲突时引导选择替代快捷键。
3. 听写：权限与音频设备就绪后播放开始音并显示状态；浮窗优先锚定可取得的光标，否则固定于当前屏幕。停止后显示处理中，Esc 可取消；失败和取消有独立提示音。声音可关闭，状态始终有文字显示。
4. 安全插入：目标仍可确认时尝试插入；焦点变化、权限缺失或结果无法安全确认时展示恢复界面。复制、原文与重试应保留用户控制，禁止自动发送。
5. 设置：语音识别模型与文本整理模型分开选择、下载和管理：首期语音识别使用千问 ASR，Whisper 留待后续；文本整理选择本地 Qwen，原文和轻微整理不需要下载该模型。麦克风输入可选择系统默认或指定设备，显示设备不可用并允许重新选择。整理力度分为原文、轻微（本地规则，无整理模型）、适度和完全重写（后两者使用本地 Qwen，完全重写先预览确认）；选择模型模式时引导下载，失败可回退原文或规则整理。提示音、快捷键、麦克风、自动插入和本地数据清除可配置。应用模板留待后续。

## 界面状态与验收

- 浮窗至少覆盖录音就绪、录音、处理、成功、取消和错误，不能仅用颜色区分；提示音开始前须确保音频采集真正就绪并避免录入提示音。
- 无语音、麦克风不可用、模型缺失、下载失败、磁盘不足、权限被撤销和插入失败均有明确解释和下一步。原型仅展示焦点变化的恢复示例。
- 模型选择展示来源、版本、下载大小、许可、磁盘需求与安装状态；两个 ASR 与 Qwen 整理模型分别管理，默认型号和资源数值待实测，不在原型中虚构。
- 结果保留政策在首次使用及隐私设置中明确，允许关闭和清除；剪贴板标记不能保证第三方不记录，不作不留痕承诺。
- 支持键盘操作、可见焦点、VoiceOver 标签、系统文字缩放和浅色/深色外观；原型为浅色方向，暗色及无障碍效果需在原生实现中验证。
- 验证目标应用中的光标锚点、不同显示器及缩放比例、长文本与焦点变化；无法取得可靠锚点时保持固定位置。

## 后续设计任务

补充权限被拒绝、下载进度、菜单栏弹出菜单、模型管理、深色外观及完整键盘操作稿；通过用户测试验证提示音、浮窗遮挡和恢复路径。技术可行性与性能门槛以产品研究文档及实测为准。

## 本地模型接入

首期由应用直接加载和管理模型，不要求安装外部模型服务。分别显示识别模型与文本模型的下载、校验、加载、就绪和失败状态，并提供取消、重试与删除。模型需要下载时说明网络、大小和来源。

## 设置分层

通用设置只呈现文字整理力度和用户可理解的效果说明；原文与轻微整理自动使用无模型路径，适度与完全重写自动调用“模型”标签页中配置的本地文本模型。识别模型和语言放在“语音识别”标签页；文本整理模型放在独立的“文本模型”标签页。选择进阶力度时若文本模型未配置或不可用，明确提示并提供前往模型设置或使用原文/轻微整理的选择，不静默降级或切换云端。

快捷键设置支持点击后录制新组合键、Escape 取消，并展示当前值。⌥ Space 为默认候选；原生实现须检测保留键与冲突、避免覆盖系统行为，冲突时说明并保留原设置。浏览器原型不能验证系统级快捷键，展示仅作交互示意。

语音识别页提供模型和语言选择：自动识别/混说、中文、英语、法语。自动检测与同一句混说并非所有模型都可靠支持，按模型能力提示；首期使用 Qwen3-ASR，Whisper 留待后续。

## 角色图标

角色素材为 [透明背景原图](assets/voice-buddy-mascot.png)，用于原型的标题区、菜单栏尺寸示意和听写浮窗。正式 macOS 菜单栏应另做适配浅色、深色及高对比度的简化模板图标，并在实际 16–22 pt 下验证辨识度；彩色毛绒原图适用于较大显示尺寸。当前只是视觉设计，尚未实现原生菜单栏或图标资源集。

## 首期模型与设置参考

首期语音识别以 Qwen3-ASR 0.6B 为默认候选，1.7B 8-bit 为进阶候选（建议 16GB 及以上，待验证）；文本整理评估较小的本地 Qwen 模型。具体启动、管理与验证见[模型集成参考](model-integration.md)。

## 界面语言

通用设置首先显示界面语言：默认跟随系统，也可手动选择简体中文或 English。首期仅支持这两种界面语言；系统首选语言不受支持时回退到英文，用户可手动切换。此设置只影响应用界面，不改变语音识别语言、整理输出语言或系统语言。原型中选择器仅演示位置，完整界面翻译与即时切换须在原生实现中验证。

## 首期独立运行方向

语音识别优先验证 speech-swift / MLX 的 Qwen3-ASR 0.6B 和进阶 1.7B 8-bit；进阶整理验证 Swift 本地 Qwen 文本模型（候选 Qwen3.5 0.8B 及适用的 MLX 运行时），具体型号由质量、延迟、内存与许可测试决定。模型页展示下载、校验、加载、就绪、失败及删除；原文与轻微整理无需文本模型。首次下载需要联网，准备完成后离线运行。若原生方案不可行，记录问题和备选方案再与产品决策协调，不自动启用外部服务或云端。

录音浮窗以紧凑胶囊展示实时音量；处理中保持紧凑，焦点丢失或重写需确认时才显示就近恢复/确认面板。原型的动态音量仅为模拟，不访问麦克风；实际应用需绑定 RMS 并处理静音、噪声与权限失败。
