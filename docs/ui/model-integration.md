## Voice Buddy 听写处理与验证

麦克风采集 → 格式检查与按引擎要求转换 → VAD 检测和保留边界余量 → Qwen ASR → 原文或规则整理／本地 Qwen 整理 → 目标安全检查与插入。参考项目实际从视频提取 16 kHz 单声道 WAV；麦克风路径需要验证输入格式、采样率和重采样质量，不照搬视频流程。VAD、静音过滤和归一化属于 Voice Buddy 首期设计；参考项目架构提及这些方向，不能据此认定当前 sidecar 已实现。按 Qwen 实测阈值，测试弱音、首尾字、噪声、纯静音和混说，降噪与增益默认保守，避免损伤语音。

指定语言应传给识别服务；自动模式不强制语言。参考服务将识别出的语言用于可选对齐，但当前返回结果不保证暴露检测语言；不要在界面声称已检测到某语言，除非契约明确返回且测试通过。混说能力需独立验证。

参考服务缓存已加载模型并将同步推理放到后台线程；需要重新测试冷/热启动、取消、并发、8GB 内存压力、崩溃恢复、临时音频清理及短语音延迟。若评估旧服务方案，服务须仅绑定回环地址并校验身份，避免将共享服务误判为自有进程。失败保留可恢复内容：ASR 失败时不伪造文本；整理失败时提示并保留原文。音频、文本和敏感路径不得进入日志。

重要限制：参考服务虽然 `/v1/models` 列出其他模型，当前 `run_local_transcription` 实际固定加载 Qwen3-ASR 1.7B，不能把列表当作可运行能力；真实能力需端到端验证。参考项目中部分测试使用模拟 ASR，不能视为 Voice Buddy 的真实识别验收。其视频项目的 OpenAI 兼容在线服务不沿用，首期坚持本地处理。
