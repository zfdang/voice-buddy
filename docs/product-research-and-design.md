# Voice Buddy：产品调研与设计建议

> 最新方向：首期优先由应用直接运行本地 ASR 与文本模型，不要求安装 Ollama、LM Studio 或 Python 服务；下文旧的服务方案作为备选研究，具体以 [模型集成参考](ui/model-integration.md) 最新决定为准。

> 状态：讨论稿｜2026-11-05｜范围：macOS 首版，Windows 后续｜结论和指标均为待验证的产品假设

## 1. 产品定位与决策

Voice Buddy 是一个离线优先的跨应用语音输入工具：用户在目标输入框触发快捷键，说完后，本机识别并按选择的力度整理，结果回到原输入位置。核心承诺是**音频、识别文本和整理上下文均不发送到远程推理服务**。模型下载和软件更新可以联网，应事先告知；断网后已安装模型仍能完成完整流程。首版无需账号，不自动发送遥测。

建议先做 macOS 菜单栏常驻应用，而非输入法。它可以保留用户现有的中文或其他输入法，通过快捷键随时启动；交互简单，也方便将来支持 Windows。其代价是辅助功能授权、焦点和粘贴兼容问题，必须通过原型验证。IME 可以更自然地参与输入会话，但用户需要切换输入源，输入法生命周期和客户端兼容性增加工程与体验成本。Apple 的 [InputMethodKit](https://developer.apple.com/documentation/inputmethodkit) 提供输入法与客户端会话的接口；这些成本是产品判断，仍需实验确认。首版不要同时实现两套入口；若跨应用插入成功率无法达到目标，再启动 IME 对照实验。

目标用户先聚焦中英文混说、经常在聊天、文档和笔记应用输入较长文本，并重视离线处理的 macOS 用户。差异化不仅是本地：同类已有本地方案，还需要可靠插入、可控改写、清晰隐私边界和中文体验。

## 3. 核心体验

1. 首次启动：介绍本地处理边界；按需请求麦克风和辅助功能权限；选择语言与推荐模型，显示下载大小、来源、许可、磁盘需求和下载进度。离线模型准备完成前不宣称可离线使用。
2. 在目标应用选中输入框，按快捷键开始；紧凑浮窗显示录音中、实时麦克风电平和取消方式；焦点丢失或完全重写待确认时显示恢复或确认面板，避免遮挡。麦克风真正就绪后播放可关闭的开始提示音，再开始采集语音；停止/处理和异常/取消各有不同的可关闭提示音，避免提示音进入录音。松开快捷键停止（切换模式为再次按键停止），显示识别、整理、插入状态。浮窗优先尝试锚定可获得的光标位置；不可用时固定在当前屏幕的稳定位置，并避免遮挡和跳动。默认快捷键暂定 ⌃⌥ Space，默认按住开始、松开结束，可在设置中改为按一次开始、再按一次结束，并允许改键；引导中检测按键有效性和冲突。Fn 可能与系统功能冲突，部分外接键盘不会向系统报告 Fn，不能假定可捕获；任何组合键也需实机测试。
3. 处理完成后仅在仍能确认原目标安全有效时插入；无法确认时保留结果并提示用户复制或手动选择位置。绝不自动按回车或发送。用户可取消；失败时展示可恢复文本。
4. 结果界面可查看原始识别和整理结果、复制与重试；用户可在设置中控制本地历史和保留期限。默认不保存音频；可恢复文本的短期保留须在首次使用时说明，并提供关闭与清除。

### 整理力度

| 模式 | 规则 | 交互与保护 |
| --- | --- | --- |
| 原文 | 不调用整理模型；保留 ASR 输出 | 可作为故障回退和质量对照。 |
| 轻微 | 优先保留 ASR 标点并用保守的确定性规则处理明确的冗余和排版；不改变事实、语气或顺序 | 建议默认；不确定内容保留。 |
| 适度 | 在不改变含义的前提下整理句子、修正明显自我纠正和分段 | 允许调整表达，不补充事实。 |
| 完全重写 | 按用户选定的目的和风格重组 | 明确标识可能改变措辞；默认先预览确认再插入。 |

示例：口述“明天，啊不，周五跟小王讨论预算，嗯，大概十万”——轻微可输出“明天，啊不，周五跟小王讨论预算，大概十万。”；适度可输出“周五和小王讨论预算，预算大约十万。”；重写可输出“请安排周五与小王讨论约十万的预算。”后者增加了请求语气，故需要确认。任何模式不得编造日期、金额、人名或承诺；处理结果为空、异常长或模型失败时保留原文并提示。语音内容是待整理的数据，不作为系统指令执行；不提供联网、执行命令或自动发送能力。

## 4. 功能范围和优先级

**首版 P0**：快捷键录音与取消、设备选择和状态反馈；VAD、本地 Qwen3-ASR（Whisper 留待后续）、原文与规则驱动的轻微整理、可选的本地 Qwen 整理、可关闭提示音；模型下载/校验/切换/删除；跨应用插入及失败恢复；中英文及混说；权限引导；快捷键冲突提示；本地数据清理；断网运行。适度整理与完全重写使用本地 Qwen，完全重写需确认。以 Apple Silicon 为首个验证目标，具体 macOS 最低版本、内存门槛和 Intel 支持以原型测试结果决定，不预先承诺。

**P1**：自定义词汇与替换、应用级模式、可选本地历史、按住/切换两种快捷键、较长录音分段、语言变体。词汇功能要分别验证识别引擎是否支持提示，不支持时只能做明确标注的后处理替换。

**以后**：选中文本语音编辑、翻译、更多语言、Windows、可配置模板和应用适配。会议录音、系统音频、自动执行任务、云同步和移动端均非首版承诺。

### 目标应用适配

先提供手动可选的聊天、笔记、待办模板，之后允许用户将 bundle ID 映射到模板；默认仅使用前台应用标识，不读取窗口内容、屏幕、网页 URL 或已有文本。例：日记输出自然段，待办将明确说出的事项分行；不推断未说出的截止日期。优先级为本次手选 > 应用规则 > 全局默认，浮窗展示当前模式并可临时切换。应用分类不可靠，未知应用使用全局默认；自动读取额外上下文必须另行明确授权并可关闭。模板依赖整理能力，手选模板与自动映射均留待 P1。

## 5. 方案与数据边界

建议 Swift/SwiftUI 原生菜单栏与权限界面，独立的录音、ASR、文本整理、插入及存储模块，通过接口隔离模型运行时与平台代码，以便未来 Windows 实现自己的录音、快捷键和插入适配器。流程：目标快照 → 录音 → 必选 VAD → ASR → 规则整理或可选本地 LLM → 安全检查/预览 → 插入或恢复。P0 的 VAD 用于过滤无语音片段和裁剪首尾静音，并保留前后余量以免截断词句；评估 [Silero VAD](https://github.com/snakers4/silero-vad) 与其运行时及许可。VAD 不能消除所有幻觉，也可能漏检低声或噪声中的语音，必须测试并提供原文恢复。长音频分段和流式预览可后续优化。

- **ASR 方案**：首期优先验证 Swift/MLX 直接加载 Qwen3-ASR 0.6B，1.7B 8-bit 为进阶候选（建议 16GB 及以上，仍须验证）；与已有 Python 实现对照，验证权重、语言、性能和许可。Whisper 与其他引擎为后续扩展。
- **整理方案**：原文和轻微整理不加载文本模型；进阶整理评估较小的本地 Qwen 模型与 Swift/MLX 运行时。模型型号须经过中文、混说、事实保持、延迟和内存测试。
- **模型管理**：应用自行管理模型的下载、版本、校验、加载和删除，显示来源、许可、大小和状态；保护其他应用的共享缓存。首次下载可联网，模型准备完成后离线运行。分别审查权重、转换版本、运行时和依赖的许可。
- **插入策略与撤销**：优先验证模拟 Cmd+V，因为目标应用可能将粘贴作为一次原生撤销操作；逐应用测试 Cmd+Z 一次撤销整段，不能保证所有应用均如此。AX 直接赋值可能影响原生撤销或选区，仅在兼容性和撤销行为验证后采用。无法安全插入时提供手动复制。剪贴板写入同一项时添加 `org.nspasteboard.TransientType`、`org.nspasteboard.ConcealedType`、`org.nspasteboard.AutoGeneratedType` [约定标记](https://nspasteboard.org/)；它们依赖第三方自愿遵守，不能保证不被读取、记录或同步，因此不得宣传为“不留痕”。提供禁用剪贴板自动插入的选项。尽可能保存原有多类型内容；异步粘贴采用状态机：快照 → 带标记写入 → 验证目标与所有权 → 发出粘贴 → 在可验证时确认消费，否则等待经测试的有界延时 → 仅当 [changeCount](https://developer.apple.com/documentation/appkit/nspasteboard/changecount) 仍属于本次写入时恢复。固定延时不能证明目标已消费；无法确认时提示并保留恢复路径，不能无条件重试以免重复插入。测试慢应用、剪贴板竞争和延迟读取；无法完整保存或恢复时明确提示。避免写入无法确认的应用或安全输入框，无法判断即停止自动插入。
- **焦点与并发**：开始时记录目标进程和可用焦点标识；结束时复核，焦点变化、窗口关闭、权限撤销或目标不可识别时进入恢复界面。使用操作 ID 防止旧任务覆盖新任务；不尝试绕过系统安全限制。兼容性是实验结论，不承诺能检测所有安全字段。
- **分发与权限**：首版计划通过独立网站分发，使用 Developer ID 签名、Hardened Runtime 和 Apple 公证；[Apple 的分发说明](https://developer.apple.com/documentation/xcode/preparing-your-app-for-distribution)将沙盒列为站外公证应用的可选项。全局快捷键、辅助功能和模拟输入的沙盒及 Mac App Store 审核可行性需逐项验证，不预断绝对无法上架。针对 macOS 15 及实际支持的版本测试权限提示、撤销和重新授权，提供图文引导，不假设某版本必然更频繁弹窗。
- **隐私**：默认关闭音频持久化、分析和崩溃内容上传；临时文件限制权限并尽快删除。历史明确设置保留期限、逐条及全部删除；操作系统备份、剪贴板管理器及目标应用可能另存数据，产品无法控制。下载/更新请求、系统权限、日志字段均需在隐私说明列出，日志不得包含音频、转录或上下文。

通用设置中用户只选择整理力度，系统自动路由：原文和轻微整理使用无模型路径，适度及完全重写调用本地文本模型。语音识别和文本模型分别设置；模型未准备好或不可用时明确提示，并提供前往模型设置或由用户选择原文/轻微整理，不静默降级。

### 本地模型集成

ASR 与文本整理各保留两种架构：应用内 Swift/MLX 运行，或通过独立适配器连接外部本地服务。首期先实现 Swift/MLX，无需用户安装 Ollama、LM Studio 或 Python 服务；外部服务为后续备选，不自动切换。先验证 [speech-swift](https://github.com/soniqo/speech-swift) 的 Qwen3-ASR 0.6B 支持，并对照 1.7B 的权重兼容性；文本整理评估小型 Qwen 与 Swift/MLX 运行时。模型下载需明确告知，应用和依赖的签名、公证、Metal 资源、离线启动与低内存行为须在干净机器验证；两种路线的细节见[模型集成参考](ui/model-integration.md)。
## 6. 验证计划与发布门槛

先做两项短原型：A. 在备忘录、浏览器网页输入框、聊天客户端、Office 类应用、终端和密码字段测试焦点、中文、换行、剪贴板竞争、权限撤销与恢复；B. 对比 Whisper 与 Qwen 候选，以及至少两个本地整理模型。收集用户授权的中文、英文、混说、口音、专有名词、噪声、静音及自我纠正样本，按说话人划分测试集；所有数据本地保存且可删除。

以下均为原型目标而非已验证 SLA，按模型、设备与冷/热状态单独报告。M1 16GB、5 秒音频、模型已加载的停止到上屏目标：原文/轻微 P50 ≤ 600ms、P95 ≤ 1000ms；本地 Qwen 适度整理 P50 ≤ 1800ms、P95 ≤ 2500ms。另测冷启动和模型下载，不计入上述热态数值。待机 RAM ≤ 80 MB、推理峰值 ≤ 1.2 GB 为 0.6B 或后续 Whisper-small 的探索性目标，不适用于 1.7B；实际权重格式、映射和内存指标须实测。1.7B 的 8-bit 权重量级已超过 1.2 GB，需单独设定设备与内存目标。明确测量进程及子进程总内存、模型映射和系统内存压力；另在 8GB 机器测 swap，不能仅凭峰值承诺不会出现内存压力。达不到时记录原因并重新决策模型、功能或目标。

分层测试：Tier 1（备忘录、信息、TextEdit、邮件、Pages）目标 ≥ 99%；Tier 2（Safari/Chromium 网页及 Slack、VS Code、Notion、微信）目标 ≥ 95%；Tier 3（Terminal、iTerm2、JetBrains，以及只读和 Vim 模式）单独记录，不假设可安全识别状态。每次试验以一次明确目标的插入为单位，记录样本数、设备、版本、失败类型及置信区间；覆盖焦点变化、多种剪贴板管理器、竞争写入、撤销、密码框和权限变化。错误插入与不可恢复的数据丢失为阻断问题，不被成功率平均掩盖。

记录字符/词错误率、专有名词错误、静音幻觉、整理事实改变率和人工偏好；按设备、模型、录音时长分别记录冷启动、停止到结果的 p50/p95、峰值内存、磁盘、电量。端到端时间包含 ASR、整理及插入；不引用竞品测试替代本机实测。目标值待基线建立后确认。建议首轮验收：断网完成全流程；测试矩阵中普通可编辑输入框至少 95% 成功插入正确位置，其余必须可恢复且不得错误插入；数字、人名、否定和日期样本的事实改变率以人工标注评估，任何高风险失败先修复。95% 是试验门槛，不是对所有应用的保证。

阶段：① 一周左右的可行性原型与基准（时间仅为规划假设）；② 完整离线闭环和小范围试用；③ 根据真实失败率完善兼容性与模型推荐；④ 再考虑应用规则、Windows 和 IME。每阶段以结果而非日历决定是否推进。若插入可靠性未达标，优先提供手动复制并试验 IME；若本地整理无法满足延迟或事实保持，则默认原文或轻微规则整理，不静默切换云端。

## 7. 待决问题

- 首批设备与最低内存、macOS 版本和是否支持 Intel；模型默认值须由基准决定。
- 用户更重视实时预览还是停止后较快出结果；长录音的时长上限。
- 本地历史默认保留多久，以及隐私与失败恢复之间的选择。
- 公共仓库的发布范围、许可证、构建产物和模型分发方式；内部研究与潜在敏感资料仅保留在 private 仓库。
- 商业模式与目标市场尚未确定；竞品定价和许可需要在发布前重新核实。

### 识别语言设置

允许选择中文、英语、法语或自动识别/多语言混说，按模型实际能力展示选项。自动语言检测不等于可靠的句内混说识别；需按模型测量并提示限制，语言不支持或检测失败时允许用户手动选择。语音识别界面只呈现模型和语言，由应用直接加载本地模型；模型不可用时引导用户处理。

### 首期参考实现

首期以 Qwen3-ASR 0.6B 和较小的本地 Qwen 文本模型为基线，1.7B 作为进阶候选，参考 video-auto-translate 的模型管理与探测经验；保留 Whisper 等后续扩展。具体行为、现有缺口与短语音适配见 [模型集成参考](ui/model-integration.md)。字幕对齐和视频处理不纳入首期。

### 界面语言

首期应用界面支持简体中文和英文；通用设置首项提供默认跟随系统及手动选择。系统语言不受支持时回退英文，手动设置优先且不修改系统语言。界面语言与识别语言独立，不自动翻译用户听写内容；需要覆盖权限、错误、菜单栏、浮窗与模型状态文案，并验证切换及持久化。
